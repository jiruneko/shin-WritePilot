# 11月11日：理解度テスト履歴（ローカル専用確認）

## 実装
- `202611110001_quiz_attempt_history.sql`：既存の非公開テストにUUIDを追加。履歴は `video_quiz_attempts` に追記。
- `submit_video_quiz` RPC：既存の採点・視聴権限チェックを再利用し、採点と保存を一つのトランザクションで実行。
- 認証されたユーザーのID、動画UUID、テストUUID、選択肢配列、設問別正誤、正答数、問題数、丸めた得点率、受験日時、公開設問スナップショットを保存。
- 同一ユーザー・送信UUIDを一意制約とトランザクションロックで重複防止。同じUUIDで回答を変えると拒否。
- 正解の選択肢番号は履歴に保存しない。正解データは既存のprivateテーブル内のみ。
- RLSは自分の履歴のSELECTだけ。INSERT/UPDATE/DELETEは一般ユーザーに許可せず、書込みは採点RPCのみ。
- 動画視聴完了や視聴権限は変更しない。動画・アカウント削除時は既存方針に合わせcascade。

## Macでの適用
未コミットのサムネイル修正などがある場合、先に `git status` を確認。変更を破棄しないこと。

```bash
cd /Users/nagatsukakenji/writepilot-quiz-local
git status --short --branch
git pull --ff-only origin feat/video-comprehension-quiz
npx supabase status
npx supabase migration list --local
npx supabase migration up --local
npm run dev -- --hostname 127.0.0.1 --port 3100
```

`migration up --local` は未適用のローカルマイグレーションすべてを適用する。事前に一覧を確認すること。本番用 `db push`、`--linked`、データを消す `db reset` は使用しない。
既存の `private.can_view_lesson` と理解度テストのマイグレーションがローカルに適用済みであることが前提。
