# 学習機能のセットアップ・確認

## PRの依存関係

この変更は、未マージのPR #2 (`feat/auth-video-lms`) の認証・動画LMSを再利用します。
追加PRのベースは `feat/auth-video-lms` です。PR #2を先にmainへ取り込んだ後、
追加PRのベースをmainへ変更して差分を確認してください。今回の作業ではマージ・本番デプロイ・本番DB操作を行いません。

## Supabaseで行う操作

対象プロジェクトを間違えないよう、まず検証用プロジェクトで実施してください。
SQLを適用してから、この変更を含むアプリを利用します（新テーブル未作成なら取得エラーになります）。

1. Supabase DashboardでWritePilotの対象プロジェクトを開き、左メニュー **SQL Editor → New query** を選びます。
2. 既存の動画LMSのSQLが未適用の場合のみ、`supabase/migrations/202610010001_video_lms.sql` の全文を貼り付けて **Run** を押します。すでに `public.profiles`・`public.videos` があり適用済みなら、この手順はスキップします。既存SQLは繰り返し実行用ではありません。
3. 新しいクエリで `supabase/migrations/202610050001_learning_progress.sql` の全文を実行します。このマイグレーションも一度だけ適用します。
4. サンプルが必要なら、新しいクエリで `supabase/seeds/sample_lessons.sql` の全文を実行します。固定UUIDと `ON CONFLICT DO NOTHING` により、繰り返しても重複しません。管理者が変更したタイトル・公開状態も上書きしません。削除済みサンプルは再実行すると復元されます。
5. **Table Editor** で `videos` にサンプル3件、`video_completions` に `user_id`・`video_id`・`completed_at` があることを確認します。SQL Editor/Table Editorの管理者接続はRLSを迂回できるので、ユーザー間の分離確認はアプリで行ってください。

新しい環境変数は不要です。既存のSupabase URL・Publishable Keyを使用し、完了保存にService Role Keyは使いません。
完了は自己申告です。動画の全編視聴を検出・強制する機能ではありません。
サンプル3教材は同じ外部デモ映像（Big Buck Bunny）を使います。正式な講義ではありません。
外部映像の提供・埋め込み可否は変わる可能性があります。

## 実環境での受け入れ確認

- 一般ユーザーAでログインし、学習ホーム・動画一覧にサンプル教材と `3教材中0教材完了 / 0%` が表示されることを確認（既存の公開教材があれば教材数は増えます）。
- 詳細で説明とサンプル表示を確認し、動画を再生。完了ボタンを押すと完了済みになることを確認。
- 一覧で `3教材中1教材完了 / 33%`。再読み込み、ログアウト→再ログインでも同じ状態を確認。
- 別ブラウザーでユーザーBにログインし、Aの完了が表示されないことを確認。同じ教材をBが完了してもAの記録は変わりません。
- Aの別タブから同じ教材を再度完了しても1件のままであることを確認。
- 通信を切断して未完了教材を保存し、エラーが表示され、成功したように表示されないことを確認。通信を戻して再試行します。応答が失われた場合はDB保存済みの可能性があるため、再読み込みでも確認できます。
- 管理者が全教材を非公開にした場合、一覧の空表示と `0教材中0教材完了 / 0%` を確認。再公開すれば既存完了が進捗に再計上されます。
- 既存のMP4再生、管理者の編集・公開切替・削除、登録・ログイン・ログアウト・退会を確認。サンプル削除ではStorage削除を呼びません。教材削除・アカウント削除時は対応する完了記録も削除されます。

## 自動検証と限界

`npm test` は実マイグレーションをPGlite（PostgreSQL）で実行し、RLS・主キーによる重複防止・DBファイル再読込後の保持・匿名や別ユーザーのアクセス拒否・削除時の連動・シードの再実行を確認します。
Auth/StorageのシステムテーブルとJWTクレームはテスト用fixtureです。Server Actionの認証・保存エラー処理・進捗計算もテストします。
`npm run test:smoke` はPC/モバイルの既存画面と未認証アクセスを確認します。
これらは実SupabaseのAuth/PostgREST/StorageやYouTubeを接続したE2Eの代替ではありません。実環境での動画再生・再ログインによる永続化・ブラウザー上の保存エラー表示は上の手順で確認してください。
