# 誤答解説・弱点分析（2026-11-12）

## 実装

- 既存の `submit_video_quiz` RPCで採点・保存した後、返された受験時の問題スナップショット、回答、正誤に解説を関連付ける。
- `src/lib/videos/quiz-feedback.ts` のカタログが問題文と選択肢の完全一致でカテゴリ・正解・解説を提供する。回答と保存済み正誤の整合性も確認し、不一致なら解説を出さない。新しい問題や編集した問題はカタログにも追加が必要。
- カタログはServer ActionとServer Componentからのみ参照。未回答の問題のpropsに正解や解説を追加しない。クライアントから受け取ったカテゴリや正解は信用しない。
- 不正解は正解と解説を表示。正解は折りたたみで解説を表示。未設定は準備中と表示。
- 動画詳細ページで本人のこの動画の最新20受験を集計。分野別正答率＝正解数÷回答数。70%未満を復習候補、分野ごとに5回答未満を参考値とする。同じ問題の反復を含むため統計的な信頼区間や独立した理解度の証明ではない。
- 未回答・未分類の問題は集計しない。取得失敗は未回答と区別する。

## DB・権限

DB変更、マイグレーション追加、ホストDBへの操作なし。`video_quiz_attempts` の既存 `questions / answers / correct` を利用。
履歴は既存のセッション用クライアントで取得し `user_id` と `video_id` を明示指定。既存RLS `own_quiz_history` が `auth.uid() = user_id` を強制し、authenticatedにはSELECTのみ許可。
既存のSECURITY DEFINER RPCは認証と教材視聴権限を検証する。今回RPCとRLSは変更しない。
